Three frontier labs launch major models in a single day, triggering an AI price war.

02
Meta abandons its open-weight Llama strategy with Muse Spark 1.1, launching its first paid closed model and developer API.

Muse Spark 1.1 is a proprietary, closed-weight multimodal reasoning model with a 1-million-token context window, native MCP support, and parallel tool-calling, available via the new Meta Model API at $1.25 per million input tokens. The pivot signals that Meta now believes the profit opportunity lies in the agentic API layer, not in distributing free open weights — a strategic reversal analysts called the most consequential AI business shift since OpenAI went commercial.

The convergence reveals that inference, now accounting for roughly two-thirds of all AI compute, has become the primary hardware battleground.
